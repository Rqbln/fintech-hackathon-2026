# Impeccable Design Context — DORA AI Analyst

## Design Context

### Users
Primary: **VC judges** evaluating a hackathon pitch in 3 minutes. They need to see AI actually working — not a dashboard with numbers, but a system that visibly reasons and cites sources. Secondary users (credibility layer): Chief Risk Officers and compliance officers at banks/insurances who need to trust the output and audit the AI's logic.

The interface must impress VCs on first sight *and* withstand regulatory scrutiny. Those two goals are in tension — resolve it by making the AI transparency the aesthetic itself.

### Brand Personality
**Precise · Sovereign · Vigilant**

- **Precise**: Every element earns its place. Pixel-perfect alignment, information-dense without clutter. The UI never guesses — it cites.
- **Sovereign**: EU-native, institutional weight. Think ECB Annual Report meets modern data tooling. Not startup flashy. On-premise means trusted.
- **Vigilant**: The interface is always watching, always surfacing risk. Motion signals live state (streaming analysis, pulsing critical nodes). Nothing is decorative.

### Aesthetic Direction
**Full light design with expressive accent palette. No dark mode.**

Base: clean white/slate-50 surfaces with deep navy typography (`#0f172a`). The lightness creates institutional credibility — this reads like professional software, not a cyberpunk demo.

Accent palette is expressive and semantic:
- **Indigo** `#4f46e5` — primary interactive, AI actions, navigation
- **Risk red** `#dc2626` — critical vendors, unmet obligations
- **Risk amber** `#d97706` — high risk, partial compliance
- **Emerald** `#059669` — met obligations, EU-sovereign vendors
- **Slate navy** `#0f172a` — headings, strong hierarchy anchors
- **Slate-200** `#e2e8f0` — borders, dividers

Graph exception: Sigma.js canvas may retain dark background for contrast (graph nodes need dark space to read). The graph panel can be the one "dark island" in an otherwise light UI.

Anti-references:
- **No** Revolut/Robinhood gradients or gamification
- **No** scroll-jacking, full-screen hero animations, or portfolio-site theatrics
- **No** grey enterprise tables from 2012 (GRC software legacy)
- **No** consumer-soft pastels or rounded-blob layouts

References: Light, structured fintech — think Stripe Dashboard, Linear, or a Bloomberg web product. Palette-expressive but never loud.

### Wow Moment
**The graph comes alive on upload.** When documents finish ingesting, nodes animate in one by one, edges draw themselves, and risk scores pulse. The graph should feel like a live threat intelligence map materializing in real time — not a static chart that appears.

### Design Principles

1. **Signal over decoration**  
   Color = risk level. Size = criticality. Motion = live state. Every visual property carries information. Remove any element that doesn't communicate data.

2. **Institutional lightness**  
   Light surfaces with deep navy anchors. The whitespace reads as precision, not emptiness. Regulatory-grade contrast ratios. Think ECB report quality — trustworthy at a glance.

3. **AI transparency as aesthetic**  
   The AI's reasoning is visible at every step: streaming verdicts, highlighted PDF clauses, cited evidence spans. The interface shows its work. This IS the product differentiator.

4. **Expressive palette, semantic meaning**  
   Indigo for action, red for risk, amber for warning, emerald for compliance. Never use color decoratively — always as signal. A VC can read the room from color alone.

5. **Motion with purpose**  
   Animate to communicate state changes (graph building, analysis streaming, panel opening). Never animate to impress. Spring physics for panels, stagger for list items, no auto-playing loops.
